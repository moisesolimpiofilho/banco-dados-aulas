# 🗄️ Banco de Dados - Aulas & Projetos Práticos

Bem-vindo ao repositório da disciplina de **Banco de Dados**. Este espaço é dedicado ao armazenamento de materiais didáticos, modelagens, esquemas relacionais e scripts SQL desenvolvidos durante as aulas.

---

## 📂 Projetos do Repositório

### 🍕 [Projeto Pizzaria](./pizzaria/)
Projeto voltado ao desenvolvimento da modelagem conceitual, lógica e física para a gestão de uma **Pizzaria**. 

* **Objetivo:** Praticar a modelagem de entidades, relacionamentos, restrições e criação de tabelas para um cenário do mundo real.
* **Acesso:** Os scripts SQL e documentações estão organizados na pasta [`/pizzaria`](./pizzaria/).

---

### 🎬 [Projeto DVD Rental](./dvdrental/)
Projeto prático baseado no banco de dados de exemplo disponibilizado pelo [PostgreSQL Tutorial](https://www.postgresqltutorial.com/).

* **Objetivo:** Explorar um banco de dados relacional completo (15+ tabelas) com suporte a consultas complexas (`JOINs`, agregação, subqueries, views, etc.).
* **Acesso:** Os arquivos de esquema, dados e consultas de exemplo estão organizados na pasta [`/dvdrental`](./pizzaria/../dvdrental/).

---

## 🚀 Como Utilizar

1. Clone este repositório para o seu ambiente local:
   ```bash
   git clone https://github.com/seu-usuario/banco-dados-aulas.git
   ```
2. Navegue até o diretório do projeto desejado (`pizzaria` ou `dvdrental`).
3. Execute os scripts `.sql` no SGBD de sua preferência (PostgreSQL, DBeaver, pgAdmin, etc.).
